**SyncDoc** is a collaborative document editing platform that enables multiple users to create, edit, and manage documents together in real time.

Built using the **MERN stack (MongoDB, Express.js, React.js, and Node.js)**, the application uses **Socket.IO** for real-time communication, allowing users to collaborate on shared documents, exchange messages, and see document updates instantly.

### Key Features
- **Real-Time Collaboration:** Multiple users can edit the same document with live updates using Socket.IO.
- **User Authentication:** Secure registration and login using JWT and bcrypt password hashing.
- **Document Management:** Create, edit, update, and delete documents.
- **Document Sharing:** Share documents with other users through email-based access.
- **Role-Based Access Control:** Assign Owner, Editor, and Viewer permissions.
- **Real-Time Chat:** Communicate with collaborators within a document.
- **AI Integration:** Use Google Gemini AI for document-related assistance.
- **Auto-Save:** Automatically save document changes to MongoDB.

### Tech Stack
- **Frontend:** React.js, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Real-Time Communication:** Socket.IO
- **Authentication:** JWT, bcrypt
- **AI Integration:** Google Gemini API
